# laudaturakatemia-mobile
One app for phones and laptops. Screens 1024 px and wider get the laptop
layout (top bar with Etusivu, Mahdollistajat and the study tabs, plus a
sidebar); narrower screens get the phone layout.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173. Resize the browser window (or use the
browser's device toolbar) to switch between the laptop and phone layouts.
